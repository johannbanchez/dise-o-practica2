Diseño de Formularios HTML

Etiquetas, campos, botones, listas y validaciones básicas

¿Qué es un formulario?

Un formulario HTML permite recopilar información proporcionada por los usuarios. Puede utilizarse para registros, encuestas, búsquedas, comentarios, solicitudes y muchas otras actividades.

Idea principal: Un buen formulario debe ser claro, ordenado, fácil de utilizar y solicitar únicamente la información necesaria.

1. Etiquetas de los formularios

La etiqueta <form> define el formulario. Dentro de él se colocan los diferentes controles que utilizará el usuario.

La etiqueta <label> identifica cada campo y ayuda al usuario a saber qué información debe proporcionar. 

<form>

    <label for="nombre">Nombre:</label>
    <input type="text" id="nombre">

</form>

Es recomendable relacionar el atributo for del label con el id del campo correspondiente.

2. Campos de entrada

La etiqueta <input> permite crear diferentes tipos de campos.

  • text – texto.
  • email – correo electrónico.
  • password – contraseña.
  • number – números.
  • date – fecha.
  • radio – seleccionar una opción.
  • checkbox – seleccionar varias opciones.

Ejemplo:

<label for="correo">Correo:</label>
<input type="email" id="correo" name="correo">

<label for="edad">Edad:</label>
<input type="number" id="edad" name="edad">

3. Listas de selección

La etiqueta <select> permite mostrar una lista de opciones para que el usuario seleccione una. 

<label for="curso">Curso:</label>

<select id="curso" name="curso">
    <option value="">Seleccione una opción</option>
    <option value="programacion">Programación</option>
    <option value="redes">Redes</option>
    <option value="ofimatica">Ofimática</option>
</select>

4. Botones

Los botones permiten realizar acciones dentro del formulario.

  • submit: envía la información.
  • reset: limpia los campos.
  • button: botón para una acción personalizada.
<button type="submit">Enviar</button>
<button type="reset">Limpiar</button>

5. Validaciones básicas

HTML permite realizar validaciones sencillas antes de enviar la información.

Algunos atributos utilizados son:

  • required: obliga a completar un campo.
  • minlength: establece una longitud mínima.
  • maxlength: establece una longitud máxima.
  • min: establece un valor mínimo.
  • max: establece un valor máximo.
  • type="email": verifica el formato básico de un correo.
<label for="nombre">Nombre:</label>

<input
    type="text"
    id="nombre"
    required
    minlength="3"
>

<label for="correo">Correo:</label>

<input
    type="email"
    id="correo"
    required
>

6. Organización de la información

Los formularios deben organizarse en grupos lógicos para facilitar su lectura y utilización.

La etiqueta <fieldset> permite agrupar campos relacionados y <legend> proporciona un título al grupo. 

<fieldset>

    <legend>Datos personales</legend>

    <label>Nombre:</label>
    <input type="text">

    <label>Edad:</label>
    <input type="number">

</fieldset>

8. Resumen

Elemento Función
<form> Define el formulario.
<label> Identifica un campo.
<input> Permite introducir diferentes tipos de datos.
<select> Permite seleccionar una opción de una lista.
<textarea> Permite introducir textos largos.
<button> Permite realizar acciones.
<fieldset> Agrupa información relacionada.
required Indica que un campo es obligatorio.
